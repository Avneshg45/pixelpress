HEIC decoding loads a ~300 KB decoder once. JPG output uses a white background — PNG transparency is flattened by design.

Why convert HEIC images?

iPhones save photos in HEIC by default for smaller file sizes, but many websites and apps do not accept HEIC. PixelPress decodes HEIC right inside your browser tab without uploading anything.

Format guide

  • JPG — universal compatibility for forms, email, and printing.
  • PNG — best when you need transparency (logos, UI assets).
  • WebP — smallest file size for web usage.

What happens to transparency?

JPG does not support transparency, so transparent pixels become white when converting PNG to JPG. Keep PNG if transparency is required.

How to shoot JPG directly on iPhone

Go to Settings → Camera → Formats → Most Compatible for future photos, and use this tool for existing HEIC files.
