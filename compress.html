How to compress an image without wrecking it

  1. Drop your files above — nothing is uploaded.
  2. Type the limit you need and pick KB or MB (100 KB is common for exam and job portals).
  3. Drag the crop frame if you only need part of the photo — the frame is what gets saved.
  4. Pick WebP for the smallest file, or JPG if the portal requires it. Press Process, then Save.

Which format should you choose?

WebP beats JPG by 25–35% at the same visual quality and every modern browser supports it. Use JPG only when a form or older app rejects WebP. PNG keeps transparency but compresses poorly for photos.

Why is the output sometimes bigger?

Already-compressed or tiny files can grow when re-encoded. When that happens, the tool keeps your original file instead and shows it in the size column. Lower max-width to force a smaller output.
